# {{title}}

An app with mnx components (`src/components/*.mnx`): HTML-first web components that work in any framework and render on the server.

| Task | Read |
|---|---|
| Write or change a component | `skills/mnx-component/SKILL.md` |
| Use a component from the app's framework, or plain HTML | `skills/mnx-consume/SKILL.md` |

`npx mnx check src/components/<name>.mnx` checks a component; `npm run dev` runs the app with hot reload; `npm test` runs the browser test. The full reference is https://github.com/journey-to-code-org/open.mnx#readme.
