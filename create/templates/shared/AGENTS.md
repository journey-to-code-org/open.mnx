# {{title}}

An app with Zubra components (`src/components/*.zb`): HTML-first web components that work in any framework and render on the server.

| Task | Read |
|---|---|
| Write or change a component | `skills/zubra-component/SKILL.md` |
| Use a component from the app's framework, or plain HTML | `skills/zubra-consume/SKILL.md` |

`npx zubra check src/components/<name>.zb` checks a component; `npm run dev` runs the app with hot reload; `npm test` runs the browser test. The full reference is https://github.com/journey-to-code-org/zubra#readme.
